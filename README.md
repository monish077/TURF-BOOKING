# Mars Arena - Turf Booking Platform

A premium and modern Turf Booking Platform that makes finding and scheduling sports arenas seamless for players while providing rich analytics and conflict-free booking tools for arena managers.

## 🚀 Key Features

* **User Dashboard**: Find and filter arenas by location/category, select open slots, and manage reservations.
* **Admin Dashboard**: Comprehensive manager portal with visual analytics, turf configuration, image uploads, and schedule conflict resolution.
* **Verification Flow**: Secure JWT-based registration, password hashing (BCrypt), and email verification using Jakarta Mail.
* **Conflict-Free Bookings**: Automatic slot blocking preventing overlapping reservations on the same turf.
* **Payment Integration**: Standard booking checkout and payment confirmation.

## 🛠️ Technology Stack

* **Frontend**: React.js, Axios, React Router Dom
* **Backend**: Spring Boot, Spring Security, Java 17/21
* **Database**: MongoDB Atlas
* **Authentication**: Stateless JWT Tokens
* **Hosting**: Vercel (Frontend), Render (Backend)
